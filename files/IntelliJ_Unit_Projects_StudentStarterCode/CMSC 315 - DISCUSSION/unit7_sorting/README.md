5. Compare and constrast each sorting algorithm based on efficiency differences, tradeoffs made, and when to each.
Bubble Sort functions well for small or nearly sorted datasets and is comparatively easy to implement. However, because it might need numerous comparisons and swaps, it could become ineffective as the dataset expands. Selection Sort has a straightforward structure as well, but before swapping, it looks for the smallest value in the remaining unsorted section of the array. Both algorithms are less effective for very large datasets because of their O(n²) time complexity.
