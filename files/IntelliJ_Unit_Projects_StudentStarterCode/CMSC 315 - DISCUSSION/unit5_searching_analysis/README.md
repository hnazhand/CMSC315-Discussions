# Unit 5 Discussion: Search Algorithms

## Overview

This assignment compares linear search and binary search.

## Learning Objectives

- Implement linear search
- Implement binary search
- Compare performance
- Analyze algorithm efficiency

## Requirements

1. Test both algorithms on a small dataset.
2. Test both algorithms on a large dataset.
3. Demonstrate edge cases.
4. Analyze performance.
5. Create a real-world search scenario.


## Discussion Board Reflection

After completing the programming assignment, add this reflection to your initial discussion post in LEO.

Your reflection should be approximately 150–200 words and address the following questions:

1. What concepts or skills did you learn while completing this assignment?
In Unit 5, I discovered how linear search and binary search tackled the same problem using different approaches. I worked on coding both algorithms and tried them out on both small and large datasets. I also came to understand the importance of testing edge cases, like looking for a value that wasn't there or dealing with an empty list. By comparing the two approaches, I gained a clearer understanding of why algorithm efficiency mattered more as data volume grew.
3. What challenges did you encounter, and how did you overcome them? A difficulty I ran into was ensuring that binary search functioned properly regardless of where the target value was located. I solved this by running the algorithm several times and verifying how the start, middle, and end positions were processed. Dividing the search process into smaller stages also assisted me in spotting and fixing mistakes.
5. Explain when to use linear versus binary search, including tradeoffs in real-world scenarios.
In practical terms, linear search would be helpful when the data wasn't sorted or when only a small set of items had to be searched. Binary search would be the superior option when the data was already sorted and searches had to be done often. The key tradeoff was that binary search demanded organized data, whereas linear search was easier but could take more time with bigger collections.
